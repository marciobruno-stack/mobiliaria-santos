# Imobiliária Santos

Este projeto consiste em um site simples para a Imobiliária Santos, apresentando informações sobre a empresa, seus serviços, corretores e opções de contato.

## Estrutura do Projeto

O projeto é composto por um arquivo HTML (`index.html`) e um arquivo CSS (`css/style.css` - embora o conteúdo do CSS não tenha sido fornecido, o HTML faz referência a ele).

## Conteúdo do Site

O site da Imobiliária Santos inclui as seguintes seções principais:

* **Topo:** Contém o logo da imobiliária e links de navegação para as outras seções do site (Sobre, Serviços, Corretores, Contato).
* **Banner:** Uma imagem de destaque para anunciar imóveis.
* **Sobre:** Apresenta a imobiliária, destacando seus 10 anos de experiência e confiança no mercado imobiliário.
* **Serviços:** Lista os serviços oferecidos pela imobiliária, como Venda, Aluguel, Financiamento e Parcerias.
* **Corretores:** Informa sobre a equipe de corretores qualificados e oferece um link de e-mail para contato.
* **Contato:** Contém um mapa (iframe) e informações de contato, incluindo telefones e links de e-mail para diferentes escritórios (Barra da Tijuca, Centro/RJ, Méier).

## Tecnologias Utilizadas

* HTML
* CSS

## Como Visualizar o Projeto

1.  Certifique-se de ter os arquivos `index.html` e a pasta `css` com o arquivo `style.css` (e a pasta `img` com as imagens referenciadas) na mesma pasta.
2.  Abra o arquivo `index.html` em um navegador web.
